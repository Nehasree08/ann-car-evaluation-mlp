# ANN-Based Classification of Car Evaluation Using MLP

## Abstract
This project evaluates a multilayer perceptron (MLP) trained with backpropagation and stochastic gradient descent (SGD) on the UCI Car Evaluation dataset. The program selects a model using validation macro-F1 and evaluates the selected configuration on a separate held-out test set. All numerical results below are generated by this run.

## 1. Problem statement
Predict car acceptability (`unacc`, `acc`, `good`, or `vgood`) from six categorical attributes: buying price, maintenance cost, number of doors, passenger capacity, luggage-boot size, and safety.

## 2. Dataset
- Dataset: UCI Car Evaluation
- Records loaded: 1728
- Input features: buying, maint, doors, persons, lug_boot, safety
- Target: `class`
- Class counts: {"acc": 384, "good": 69, "unacc": 1210, "vgood": 65}
- Missing rows removed: 0
- Reference: https://archive.ics.uci.edu/dataset/19/car+evaluation

## 3. Methodology
Categorical features are transformed using one-hot encoding inside a scikit-learn Pipeline. This ensures the encoder is fitted on training data only. The split uses random seed 42 and stratification:
- Training subset used during experiments: 1036 records
- Validation subset for configuration selection: 346 records
- Final test subset: 346 records

The held-out test set was not used to choose hyperparameters. After selecting the best configuration by validation macro-F1 (accuracy used as a tie-breaker), the model was refitted on the combined training and validation subsets and evaluated on the test set once.

## 4. Model and training
- Model: `sklearn.neural_network.MLPClassifier`
- Hidden layer sizes: (32,)
- Activation: ReLU
- Solver: SGD
- Learning rate schedule: adaptive
- Initial learning rate: 0.05
- Batch size: 32
- Momentum: 0.9; Nesterov momentum enabled
- Maximum epochs: 800
- Epochs run in final fit: 313
- Convergence warning in final fit: False

Backpropagation calculates gradients of the classification loss and SGD updates network weights using minibatches. The adaptive learning-rate schedule reduces the rate when progress stalls.

## 7. Error analysis and generalization
Inspect the confusion matrix to identify which classes are confused. Compare macro-F1 with weighted-F1: a gap may indicate that performance differs across classes. Review `test_predictions.csv` for examples where actual and predicted labels differ. The test set is a single stratified holdout, so results estimate performance under this split and do not prove performance on every real-world car market.

## 8. Limitations
1. The dataset is small and categorical, and was generated from a structured decision model rather than collected as a broad sample of current vehicles.
2. The target reflects the dataset's acceptability labels, not real-world market demand or safety certification.
3. A single train/validation/test split can yield variable estimates; repeated stratified cross-validation would strengthen the evaluation.
4. One-hot encoding does not explicitly model the ordinal meaning of some categories.
5. MLP results depend on random initialization and hyperparameters; convergence warnings and the loss curve should be checked.

## 9. Conclusion
This run implements an ANN classifier using an MLP and SGD, compares controlled configurations on a validation set, and reports performance on a held-out test set. The reported numbers are specific to the saved run; rerunning with different software versions or settings may produce different results.

## 10. Reproducibility
Run `python main.py`. The random seed is fixed at 42. Library versions and split sizes are saved in `results/run_metadata.json`. Install dependencies from `requirements.txt`.
